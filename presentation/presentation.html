Phase 0 — Before We Build

Why We Need Analysis First

Before touching Shopify themes or writing a single line of code, we must understand the client, location, and customer. This analysis is what makes the UI look professional and work perfectly on mobile, laptop, and every screen size.

Skip analysis → generic store that looks like every other template. Do analysis first → tailored UI that feels like a real UK fashion brand and converts on every device.

👤

Client Analysis

Who is paying for this store and what do they need?

  • Business goals (test products internally)
  • Brand personality & tone
  • Budget & timeline constraints
  • What "success" looks like
  • Team roles & decision makers
📍

Location Analysis

Where are we selling and what does that market expect?

  • UK market — GBP, VAT, shipping zones
  • No physical store (online only)
  • UK consumer law (14-day returns)
  • Payment methods (Visa, Apple Pay, Klarna)
  • Seasonal trends (UK weather/fashion)
🛍️

Customer Analysis

Who shops here and how do they behave online?

  • Age 22–45, UK online shoppers
  • Men's + women's fashion buyers
  • Mobile-first browsing (70%+ traffic)
  • Expect fast checkout & clear sizing
  • Trust signals: reviews, returns, policies

What analysis tells us about UI

  • Colours: UK fashion = clean neutrals + one bold accent (not loud Indian-market palettes)
  • Typography: Modern sans-serif, readable at 16px on mobile
  • Navigation: Men / Women / Accessories — clear gender split our customers expect
  • Hero image: Lifestyle photography, not stock corporate shots
  • Trust: UK shipping, free returns, GDPR privacy policy visible in footer
  • Checkout: GBP pricing, UK postcode lookup, Apple Pay enabled

Cross-Platform UI

Responsive on Every Device

Over 70% of UK fashion shoppers browse on mobile. Our Shopify store must look and work perfectly on phones, tablets, laptops, and desktops — without building separate versions.

📱 Mobile
375px – 480px
📱 Tablet
768px – 1024px
💻 Laptop / Desktop
1280px+

Shopify responsive built-in

  • Free themes (Dawn) are mobile-first by default
  • Theme editor shows desktop / tablet / mobile preview
  • Sections auto-stack on smaller screens
  • Touch-friendly buttons (min 44px tap targets)
  • Shopify CDN serves optimised images per device

Recommendation

Pick Basic (£19/mo)

Why Basic works for us

  • Internal testing — no real sales volume
  • 1–2 people setting up initially
  • Full theme customisation included
  • Unlimited test products
  • Shopify Payments test mode
  • Developers use Collaborator accounts (free)

Upgrade to Grow (£49/mo) when

  • 3+ team members need daily admin login
  • Marketing manages campaigns in admin
  • QA handles orders/refunds daily
  • Need professional reports

Break-even at ~£10k/mo real sales. Irrelevant for internal testing.

Before We Start

Pros & Cons to Consider

✅ Pros

  • Live in 1–3 days with free theme
  • No hosting, SSL, or security to manage
  • UK GDPR + Consumer Rights Act tools
  • Mobile-first themes (90+ Lighthouse)
  • 8,000+ apps if we need features later
  • Test mode — no real charges
  • Theme code exportable to GitHub

⚠️ Cons & Mitigations

  • £19–49/mo cost → Acceptable for test infra
  • Theme layout limits → Customise within editor
  • App costs add up → Start with zero apps
  • Vendor lock-in → OK for test store
  • Liquid not React → Similar to Jinja/Twig
  • No SQL access → Use Admin API
  • Basic = 1 login → Use Collaborators
