The problem

Why we built ShopifyProductAdd

UK fashion e-commerce teams need to launch products fast — but every competitor listing is a manual copy-paste job across scrape, copy, images, variants, and Shopify admin.

❌ Without automation

  • Open competitor product page → copy title, description, specs by hand
  • Download image → edit in Photoshop → upload to Shopify
  • Manually create 6 sizes × 3 colors = 18 variant rows in admin
  • Rewrite copy so it's not a copyright copy of the source
  • Assign vendor, category, collection — repeat for every SKU

✅ With ShopifyProductAdd

  • Paste one Product URL in Google Sheets
  • Workflow scrapes, rewrites, QA-checks, and builds variants automatically
  • Shopify draft product ready in 2–4 minutes
  • Ops team controls presets via sheet — no code deploy per brand
  • Scale from 5 products/day to ~20/hour per operator
Core insight: The bottleneck isn't Shopify — it's the human hours between finding a competitor product and having a publish-ready draft.

Our solution

ShopifyProductAdd — AI automation pipeline

A production n8n workflow that runs end-to-end in real time when you edit a Google Sheet row. No batch jobs, no overnight waits — trigger fires → product builds.

Sheet URL → Smart Scrape → AI Listing → QA ≥ 90 → Photoroom → Shopify Draft

What AI does

  • Rewrites 100% original product copy (not competitor text)
  • Fills scrape gaps only — code extracts first (cheaper, faster)
  • Vision analysis verifies color/material from image
  • QA scores listing quality — must pass ≥ 90

What humans still do

  • Paste competitor Product URL
  • Set sell price in Shopify admin after draft
  • Review QA FAIL rows and approve edge cases
  • Edit LookupTables / VariantLibrary presets (one-time setup)
Use case 1

Competitor URL → Shopify draft in under 3 minutes

Merchandiser spots a trending Everlane linen shirt. Paste the URL → get a draft with title, description, image, 6 sizes × 3 colors, vendor, and collection assigned.

  1. Copy everlane.com/products/... into Master_Sheetv1
  2. Sheet formulas auto-fill vendor, category, variant preset from LookupTables
  3. n8n scrapes via Shopify .json API (fast path)
  4. AI writes UK listing → QA PASS → Photoroom cleans image
  5. Shopify draft created — operator sets price and publishes
Best demo site: Everlane (Mode A · ★☆☆ Easy) — reliable scrape, full variants, ~2 min end-to-end.
Use case 2

UK fashion multi-variant catalog at scale

Launch a 50-SKU seasonal drop without manually building variant matrices in Shopify admin for every product.

VariantLibrary presets

  • uk-shirts — Size XS–XXL × 10 sell colors
  • uk-jeans — Waist × Length × Color (Levi's-style)
  • uk-shoes — UK Size 6–12 × 10 colors (Tecovas boots)
  • custom — any Shopify option names you type

Example output

  • 1 URL → 6 sizes × 3 colors = 18 SKUs auto-created
  • Inventory split across variants (default 10 total)
  • Scraped sizes override preset when competitor data exists
  • Collection auto-assigned from category keyword match
Coming: Per-color images on storefront (ColorImageLibrary) — today all variants share one hero image.

System design

End-to-end architecture

Google Sheets Trigger
  ├─ PASS row? → skip (no duplicate)
  ├─ needs scrape? → Route → HTTP | .json | Browserless
  │    → Prepare page → AI scrape → Apply → Update sheet → Re-read formulas
  └─ Active product row (merge scrape + sheet formulas)
      → Has image? → Photoroom → ImgBB → Analyze image
      → AI write listing → Check overlap → AI QA score
      → QA ≥ 90? → Build Shopify product (variants)
      → Create draft → Upload image → Set stock → Collection → Sheet URLs
Design principle: Code extracts first (free, fast). AI fills gaps only. Browserless only for bot-protected domains (~20% of URLs).

Honest assessment

Current limitations

⚠️ Image: One hero image per product. All colors show same photo until ColorImageLibrary ships.
⚠️ Bot protection: Mango, Macy's, Zara need Browserless API token. Without it → NEEDS_BROWSER / partial scrape.
⚠️ Variants: Scrape misses sizes on 40–45% of bot-protected sites. VariantLibrary defaults fill the grid — may not match competitor exactly.
⚠️ Price: Competitor price is reference only. Sell price set in sheet manually — not auto-mapped to Shopify yet.
⚠️ Throughput: ~20 products/hour single-threaded. No parallel batch without engineering.
⚠️ Legal: Scraped images used as input to Photoroom — for internal test store. Public launch needs owned or licensed images.
