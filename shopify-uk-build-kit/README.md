# Shopify UK Build Kit — Men's & Women's Fashion (Internal Test Store)

This folder contains everything the team needs to build a polished UK Shopify store for **men's and women's clothing and accessories**. The store has **no physical location** and is used **internally to test products we are building**.

## Project at a Glance

| Item | Detail |
|------|--------|
| **Market** | United Kingdom |
| **Catalog** | Men's & women's apparel + accessories |
| **Purpose** | Internal product testing (not public launch) |
| **Theme** | Free Shopify theme (recommended: **Dawn** or **Craft**) |
| **Currency** | GBP (£) |
| **Shipping** | UK only (no physical store / no click-and-collect) |
| **Legal** | UK GDPR + Consumer Rights Act compliant policies |

## Recommended Free Themes

| Theme | Best for | Why |
|-------|----------|-----|
| **Dawn** | Clean, modern fashion | Fast, minimal, great on mobile |
| **Craft** | Editorial / lifestyle look | Strong imagery, storytelling layout |
| **Sense** | Bold hero sections | Good for seasonal campaigns |
| **Refresh** | Product-focused catalog | Clear category navigation |

Install via: **Online Store → Themes → Explore free themes**

## Quick Start (15 minutes)

1. Sign up at [shopify.com/uk](https://www.shopify.com/uk) (3-day free trial)
2. Set store country to **United Kingdom**, currency to **GBP**
3. Install **Dawn** (or Craft) free theme
4. Run prompts from files `01` → `06` in ChatGPT or Claude
5. Add 5–10 test products (men's + women's mix)
6. Enable **Shopify Payments** (test mode for internal use)
7. Publish store on password-protected mode until ready
