# Colour Scheme Prompt

Use after brand name and logo are decided. Paste into your AI conversation or a new chat with brand context attached.

---

## Prompt (copy from here)

```
Brand: [INSERT BRAND NAME]
Store: UK men's and women's clothing and accessories (Shopify, free theme)
Audience: UK online shoppers, 22–45, everyday and smart-casual fashion
Brand tone: modern, clean, confident, inclusive

Recommend a complete colour scheme for Shopify theme settings (Dawn or Craft theme).

Provide hex codes and rationale for each:

1. Background — keep #FFFFFF unless a soft off-white is better
2. Text — primary body text colour (must pass WCAG AA contrast on white)
3. Solid button background — PRIMARY brand colour (bold, conversion-friendly)
4. Solid button label — text colour on primary buttons
5. Outline button — border and text colour for secondary CTAs
6. Accent — for sale badges, links, hover states
7. Shadow — subtle shadow colour for cards and buttons

Also recommend:
- One "men's section" accent (optional, subtle)
- One "women's section" accent (optional, subtle)
- Whether dark mode header would suit this brand

Explain why each colour works for UK fashion e-commerce and our target audience.
Format as a table: Setting | Hex | Usage
```

---

## How to Apply in Shopify

1. Online Store → Themes → **Customize**
2. Click **Theme settings** (left panel) → **Colors**
3. Enter hex codes from the AI output:

| Shopify Setting | Maps to |
|----------------|---------|
| Background | Background |
| Text | Text |
| Solid button background | Primary button |
| Solid button label | Button text |
| Outline button | Secondary button |
| Accent | Links, badges |

4. **Save** and preview on mobile

## UK Fashion Colour Guidance

| Approach | Example palettes | Best for |
|----------|-----------------|----------|
| **Neutral + bold accent** | White, charcoal, coral CTA | High conversion, unisex |
| **Earthy tones** | Cream, olive, terracotta | Sustainable / lifestyle feel |
| **Monochrome** | Black, white, grey | Premium minimal look |

For internal testing, pick one scheme and document it in the Excel tracker so all team members use the same colours.

## Accessibility Check

Before finalising, verify contrast at [webaim.org/resources/contrastchecker](https://webaim.org/resources/contrastchecker/):
- Body text on white: minimum **4.5:1** ratio
- Button text on button background: minimum **4.5:1** ratio
