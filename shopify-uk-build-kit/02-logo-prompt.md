# Logo Design Prompt

Use this **after** you have chosen a domain/brand name from [01-brand-domain-prompt.md](./01-brand-domain-prompt.md). Paste into the **same AI conversation** so it keeps brand context.

---

## Prompt (copy from here)

```
Brand name chosen: [INSERT YOUR BRAND NAME]

Context: UK Shopify store selling men's and women's clothing and accessories. Online only, no physical store. Internal test environment for our product team. Brand tone: modern British fashion — clean, confident, inclusive.

Design a logo concept that:
- Works on a white website header and on product tags
- Reads clearly at mobile size (favicon and nav bar)
- Appeals to both men's and women's fashion without being gendered
- Uses maximum 2–3 colours
- Feels contemporary, not corporate or luxury

Deliver:
1. Logo concept description (icon + wordmark, or text-only)
2. Colour palette with hex codes (primary, secondary, accent)
3. Typography recommendation (Google Fonts compatible)
4. Why this design fits a UK fashion brand
5. Generate the logo image

Constraints:
- No clip-art fashion silhouettes (no dress/shirt icons)
- No Union Jack unless subtle
- Scalable vector style preferred
```

---

## Refinement Commands

After the first generation, iterate with:

| Request | Example |
|---------|---------|
| Simplify | "Make it more minimal — text only, no icon" |
| Recolour | "Use navy #1B2A4A and warm sand #E8DCC8" |
| Variations | "Give me 3 versions: icon+text, text-only, monogram" |
| Mobile test | "Show how it looks at 32px height" |

## Export & Upload

1. **Remove background:** [remove.bg](https://www.remove.bg/upload)
2. **Upload to Shopify:** Settings → Brand → Logo
3. **Favicon:** Settings → Brand → Favicon (use square crop of logo)
4. **Save source files** to team shared drive / Jira attachment

## Quality Checklist

- [ ] Readable at 32×32 px (favicon size)
- [ ] Works on white and light grey backgrounds
- [ ] No more than 3 colours
- [ ] Team approved in stand-up or Slack
- [ ] Uploaded to Shopify Brand settings
