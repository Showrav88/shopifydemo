# Homepage Hero Banner Prompt

Use after brand, logo, and colours are set. This prompt helps you find or brief the perfect hero image.

---

## Prompt (copy from here)

```
Brand: [INSERT BRAND NAME]
Store: UK men's and women's clothing and accessories
Theme: Shopify free theme (Dawn or Craft)
Hero section: full-width banner above the fold

I will source images from Shopify's free image library (or Unsplash).

Give me:

1. THREE search terms (2–4 words each) to find hero banner images in Shopify's image search
2. Art direction for the winning image:
   - Composition (framing, negative space for headline text)
   - Mood and lighting
   - What to include and what to avoid
   - Whether to feature models, flat-lay, or lifestyle scene
3. Recommended headline text (5–8 words) for the hero overlay
4. Recommended sub-headline (one sentence)
5. CTA button text (2–3 words)
6. Why this visual approach converts for UK fashion shoppers aged 22–45

Constraints:
- Image must work with text overlay on the left or centre
- Must represent BOTH men's and women's fashion (or be gender-neutral)
- No cluttered backgrounds — clean enough for mobile
- Season: current UK season or timeless all-season
```

---

## Where to Find Images

| Source | How |
|--------|-----|
| **Shopify image library** | Theme editor → select image → **Explore free images** |
| **Unsplash** | [unsplash.com](https://unsplash.com) — search terms from prompt |
| **Pexels** | [pexels.com](https://pexels.com) — free commercial use |

## Recommended Search Terms (starting points)

Try these if the AI output needs a nudge:

- `fashion model neutral`
- `clothing flat lay minimal`
- `street style london`
- `wardrobe capsule neutral tones`

## Hero Setup in Shopify

1. Online Store → Themes → Customize
2. Click the **Image banner** section on the homepage
3. Upload or select image from free library
4. Set overlay opacity to **30–50%** if text is hard to read
5. Add headline, sub-headline, and CTA button
6. Link CTA to **/collections/all** or **Men** collection
7. Preview on **mobile** — crop/position image so faces aren't cut off

## Mobile Checklist

- [ ] Headline readable without zooming
- [ ] CTA button thumb-reachable
- [ ] Image loads under 3 seconds (compress if needed)
- [ ] Text contrast passes on both desktop and mobile
