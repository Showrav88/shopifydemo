# Footer Description Prompt

Short prompt for the footer tagline. Use after brand identity is finalised.

---

## Prompt (copy from here)

```
Brand: [INSERT BRAND NAME]
Store: UK online shop for men's and women's clothing and accessories
No physical store — ships across the United Kingdom
Purpose: professional e-commerce presence (internal product testing)
Tone: trustworthy, modern, friendly — not corporate

Write a footer description (2–3 sentences, max 280 characters).

Must mention:
- What we sell (men's and women's fashion + accessories)
- UK delivery
- Commitment to quality and easy returns

Do NOT mention:
- That this is a test/internal store
- Specific founder names (use "our team" instead)
- Physical store or visit-us language

Also provide:
- A shorter version (1 sentence, max 100 characters) for mobile footer
- Suggested footer link labels: Shop, Help, Company, Legal
```

---

## Where to Add in Shopify

1. Online Store → Themes → Customize
2. Scroll to **Footer** section
3. Paste description into the **Text** or **Brand information** block
4. Add footer menu links:

| Column | Links |
|--------|-------|
| **Shop** | Men, Women, Accessories, New In, Sale |
| **Help** | Shipping, Returns, Contact, FAQ |
| **Company** | About Us, Careers (optional) |
| **Legal** | Privacy Policy, Terms of Service |

## Footer Extras to Enable

- [ ] Payment icons (Visa, Mastercard, Amex, Apple Pay)
- [ ] Social links (Instagram, TikTok — add when accounts exist)
- [ ] Newsletter signup (Shopify Email — free tier)
- [ ] Copyright line: `© 2026 [BRAND NAME]. All rights reserved.`
